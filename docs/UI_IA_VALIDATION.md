# 手机信息架构与状态门槛验证

2026-10-03 UTC。本批独立重构界面信息架构及控制层，不代表真实保险库产品链或安全验收完成。

## 界面与状态

首屏只输入 HTTPS 服务地址。下一步实际请求 GET /instance-info，检查 Harmonia 产品字段、公开协议 major 1 和三个注册开关；普通 HTTP 200、错误 JSON、协议不兼容不能成功。实例首次注册可用时默认进入注册页，否则进入登录页；关闭注册时没有注册链接。连接不代表登录，登录不代表设备可信。

账号未登录、等待设备授权、受限恢复、可信设备、显式合成演示分别由 controller 管理。内部路由、返回和深链接不能绕过门槛；退出立即隐藏旧视图，旧异步结果不能恢复内容。退出清理在途禁止新连接、登录、恢复或服务器切换；重复退出合并，仅当前清理实际成功解除限制。操作身份阻止旧请求的 finally 清除新请求 busy。

保险库导航为环境、设备、设置。环境列表进入环境详情，再进入独立变量编辑页。设备一级仅列表和状态，授权范围与审批核对进入二级页；恢复码管理位于设置的账号安全下。合成演示必须显式开发编译开关并点开发入口，未连接任何真实账号，不伪造登录、审批或恢复成功。

前台授权提示只接受未来已核验原生 API 的公开元数据：按账号代际、PairID、序号和状态去重，一条 active 提示，稍后不反复弹；过期或撤销关闭请求详情。后台不检查或主动提示，不新增推送权限。当前没有真实请求列表 API，自动提示与 badge 保持不可用；手动 PairID 不能冒充服务器请求。

系统窗口 inactive 仅遮罩，返回不循环应用锁；真正后台按原生锁配置要求重新验证。App 锁与 PIN 密钥 provider 尚未实现，设置禁用。取消、失败或暂时锁定不会触发 PIN 降级。界面解锁不能代替登录、设备信任或逐操作私钥授权；controller 测试使用明确合成状态来源，不证明实际系统认证。

## 实际结果

- 控制层 32/32 测试通过，无 UI 单元测试。覆盖未登录与受限恢复门槛、冷启动、重开、深链接、账号登录与设备可信分离、只读角色、非乐观变更、异步退出、延迟原生清理、旧请求 busy、连接分类与重复点击、前台事件去重、过期撤销、隐私遮罩与取消不降级。
- Flutter 静态分析通过。
- 本机实际 Android 合成预览 APK 构建通过（8.0 秒），该产物在最后退出清理/busy时序修复前构建；当前冻结源码重新构建待验。实际运行截图在隔离 AVD 可用后单列，不把构建等同运行。
- UI 由本机订阅 Claude Opus 5.5 medium 单次调用生成；仅公开合成源码与公开 UI 合同输入，工具/MCP 禁用、无会话持久化、无计费 API。输出超过软体积目标，没有追加模型调用。状态、gateway、校验及测试由 Codex 实现。
