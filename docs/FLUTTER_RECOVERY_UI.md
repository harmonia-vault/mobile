# 手机恢复界面

恢复入口使用现有 C「砂岩」组件与浅深主题，由本机 Claude Opus 5.5、中等思考实现。Codex 只接入既有业务合同和表单安全生命周期，没有修改视觉系统。

## 已接入

恢复界面读取 `RecoveryActions` 的只读状态；按钮只调用合同中明确允许的动作。它包含当前完整恢复码、新码完整重输、转换的封存与提交、环境角色和期限的显式选择、设备验证以及原操作查询。关闭本机内存过程与关闭服务器旧恢复分支分别处理，后者另需确认。

界面不创建操作 ID、不重新签名原包、不把登录或登记接受视为设备可信，也不修改原生能力白名单。密码仅当次内存使用；可控恢复码字节在调用结束或异常时清零，输入框在调用前清空。Dart 字符串无法保证彻底擦除。

父界面保留按账号、服务和页面生成的 `ValueKey`。范围变化时当帧卸载旧表单；恢复面板另同步清空输入、环境角色与期限选择、破坏性确认。真正后台清理可控输入，短暂系统认证的 `inactive` 只保留同一范围表单。延后隐藏显示码的回调绑定控制器与范围，不能影响后来建立的新范围。
