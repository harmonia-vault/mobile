## 实际 Flutter 明暗预览

同一冻结 Android debug APK 在独立、无真实账号的 Android 34 ARM 模拟器中安装运行。通过公开 Android SDK 的 accessibility 节点定位和真实点击进入页面，分别在系统浅色、深色主题下生成连接页、环境列表、管理环境详情、只读环境详情、设备和设置各一张截图，共 **12 张原始 1080×2400 PNG，通过**。截图未裁剪或编辑；不是 HTML 渲染图。

默认仍停在连接页，只有点击“打开演示模式”才进入纯内存合成数据。变量值保持遮罩，演示页面有明确标记。环境、设备、设置的整项圆角高亮随真实导航点击切换；只读环境的编辑入口禁用。逐一目视全部 12 张图，在此次设备设置及截图可见区域内没有发现截字或错误画面。应用自身进程日志未出现本轮检索的 `E/flutter`、`Unhandled Exception` 或 `RenderFlex overflow` 行；这不代表所有运行错误均已排除。

首轮截图脚本检查失败：仅读取窗口子输出时未得到前台焦点字段，断言失败，在生成 PNG 前停止。实际 UI 树已显示正确预览包的连接页。原失败记录保留；第二轮只修正测试脚本，改为完整窗口、已恢复的 Activity 与实际 UI 树包名校验，同一 APK 重试通过。没有为此修改界面、业务、认证门槛或原生代码。

清理通过：仅本次独立预览应用已卸载；原有 171 个包名的基线完全一致，没有新增或缺失。模拟器系统主题恢复原值，本轮启动的模拟器进程正常退出，所占端口释放，已有模拟器保留。没有操作其他模拟器、重启或重配 ADB 服务、修改系统 PIN、时间或安全设置。

本轮使用的是合成预览，没有运行真实连接、注册、登录、邮箱证明、完整恢复码重输、设备批准或恢复流程，也没有验证编辑、删除和危险操作确认的完整交互。硬件键盘、TalkBack、不同字号和屏宽仍未跑。以上截图不能作为真实账号、加密、授权或生产可用性的验收。
