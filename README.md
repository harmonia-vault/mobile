# Harmonia 手机端

Harmonia（和弦）是一个自托管的环境变量同步工具：在手机上集中管理环境变量，按设备授权，同步到电脑和运行环境中使用。

本仓库是 Harmonia 的手机端，支持 Android 与 iOS，用于管理环境、变量和设备授权。需配合 [服务端](https://github.com/harmonia-vault/server)与[命令行客户端](https://github.com/harmonia-vault/core-go)使用。

## 功能

- 按项目或用途创建环境，管理其中的变量
- 批准电脑的配对请求，为其选择可访问的环境、权限和有效期
- 调整或撤销已授权设备的权限
- 使用系统认证保护应用

## 开始使用

1. 打开应用，填写服务地址，例如 `https://vault.example.com`。
2. 注册账号并完成邮箱验证。
3. 初始化账号，保存恢复码并按提示确认。
4. 创建环境并添加变量。

之后在电脑上通过[命令行客户端](https://github.com/harmonia-vault/core-go)发起配对，在手机上核对短码并批准即可同步。

## 更换手机与重置

- **恢复访问**：手机丢失或更换时，在登录页选择“恢复访问”，使用邮箱、密码和恢复码在新手机上恢复。
- **重置账号**：遗失恢复码时，可通过邮箱验证重置账号。重置会**永久删除**原有数据和全部设备授权，无法用于找回数据。
- **App PIN**：忘记后无法找回，需要清除本机数据后重新登录和授权。

## 注意事项

- 恢复访问必须使用恢复码，遗失后只能重置账号，请妥善保存。
- 预览模式中的内容仅用于演示，不会同步到账号。
- 项目处于实验阶段，请勿用于生产环境的凭据。
